# PrismDen · 棱镜降噪图像处理系统 V1.0

一个完全运行在浏览器中的图像降噪与处理工具。核心降噪算法为**双边滤波（Bilateral Filter）**，在 Web Worker 中本地执行，无需部署任何后端服务器。所有算法与界面均由原生 HTML / CSS / JavaScript 实现，不依赖任何图像处理库或前端框架。

本项目为个人开发作品，可作为计算机软件著作权登记（登记软件名称：PrismDen 棱镜降噪图像处理系统，版本号：V1.0）的源代码与运行说明依据。

## 四、核心算法：双边滤波

双边滤波在普通高斯模糊基础上引入**值域权重**，使滤波核同时考虑空间距离与像素值差异，从而在平滑噪声的同时保留边缘。

输出像素值计算公式：

```
I'(p) = Σ_{q∈Ω} w_s(‖p−q‖) · w_r(‖I(p)−I(q)‖) · I(q)
        ─────────────────────────────────────────────
        Σ_{q∈Ω} w_s(‖p−q‖) · w_r(‖I(p)−I(q)‖)

w_s(d) = exp( −d² / (2σₛ²) )        # 空间域高斯
w_r(Δ) = exp( −Δ² / (2σᵣ²) )        # 值域高斯
```

其中 `σₛ` 控制空间邻域范围，`σᵣ` 控制对像素差异的容忍度：`σᵣ` 越小边缘保持越强。

### 性能优化

1. **值域权重因式分解**：RGB 三通道值域权重独立计算，化简为三层查表加两次乘法。
2. **256 项查找表（LUT）**：值域 `exp()` 预计算为长度 256 的 LUT，内层循环零 `exp()` 调用。
3. **倒数乘法替代除法**：权重归一化使用 `1/Σw` 一次倒数乘累加。
4. **边界外提**：图像边界判断移出最内层循环。
5. **Web Worker 分块并行**：图像按块切分，逐块回传进度，避免主线程阻塞。
6. **零拷贝传输**：`postMessage` 使用 `Transferable` 直传 `ArrayBuffer`，不复制像素数据。
